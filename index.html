Sobre o projeto

Este projeto apresenta cinco problemas comuns em redes de computadores. Cada situação contém possíveis causas, comandos de diagnóstico e procedimentos para solucionar as falhas.

Ferramentas de diagnóstico

IPCONFIG

Exibe as configurações de rede do computador.

PING

Testa a comunicação entre dispositivos.

NSLOOKUP

Verifica a resolução de nomes pelo DNS.

DHCP

Distribui automaticamente configurações de IP.
